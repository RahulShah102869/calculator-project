# 🧮 Modern Calculator

A modern, responsive calculator web application built using HTML, CSS, and JavaScript. This project provides a smooth calculation experience with a clean, glassmorphism-inspired user interface.

## 🌐 Live Demo

🔗 **Website:** [Try Calculator](https://calculator-pro-ject.netlify.app/)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, animations, and responsive design
- **JavaScript** – Calculation logic and interactive features
- **Netlify** – Website hosting and deployment

## ✨ Features

- Basic arithmetic operations (+, −, ×, ÷)
- Percentage calculations
- Backspace functionality
- Keyboard input support
- Responsive design
- Modern glassmorphism-inspired UI
- Smooth and user-friendly interface
